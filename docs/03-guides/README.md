# Guides

**Task-oriented walkthroughs** for specific tools, with more depth than a
workflow gives.

A [workflow](../01-workflows/) tells you which commands to run in what order. A
guide covers one tool in detail — flags, edge cases, troubleshooting.

## A note on age

These guides predate the v5.0.0 companion functions. Their tool-level detail is
still accurate; where they describe how a tool fits the wider lifecycle, the
[workflows](../01-workflows/) are newer and take precedence.
