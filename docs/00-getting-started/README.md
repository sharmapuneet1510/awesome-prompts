## Reading concepts first

[concepts.md](concepts.md) is listed third but is the one most worth reading
before you start, particularly:

- **Why decisions are separate from state** — the idea the whole system rests on.
- **Gates** — why a command refuses instead of warning.
- **Labels** — why output is tagged FACT, INFERENCE, PROPOSAL, or DECISION.

Without those three, the gates read as obstruction rather than design.
